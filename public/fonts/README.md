# 카드뉴스 전용 폰트 파일

`pretendard`(기본 폰트), `@fontsource/noto-sans-kr`, `@noonnu/dos-gothic`는 npm 패키지로 설치되어 자동으로 적용됩니다.

아래 세 폰트는 라이선스상 npm 패키지로 배포되지 않는 무료 한글 폰트라 이 저장소에 포함하지 않았습니다.
눈누(noonnu.cc)에서 직접 다운로드한 뒤 이 폴더에 넣어주세요. 파일이 없으면 각 폰트는 자동으로
손글씨 계열(cursive) 시스템 폰트로 대체되어 표시되므로 앱 동작에는 문제가 없습니다.

- `okaydandan.woff2` — 오케이 딴딴체
- `ggubulrim.woff2` — 꾸불림체
- `cocochoitoon.woff2` — 그리운 코코초이툰체
